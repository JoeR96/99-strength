# A2S2 Hypertrophy - Validation Data

## TM Progression Rules (Identical for all exercises)

| AMRAP vs Target | TM Adjustment |
|----------------|---------------|
| 2+ under target | -5% |
| 1 under target | -2% |
| Hit target exactly | 0% (no change) |
| 1 over target | +0.5% |
| 2 over target | +1% |
| 3 over target | +1.5% |
| 4 over target | +2% |
| 5+ over target | +3% |

**Additional rules:**
- If no AMRAP result is entered → TM carries forward unchanged
- Deload weeks have rep-out target = "n/a" → no AMRAP, TM carries forward
- Working weight = `MROUND(TM × week_intensity%, rounding_increment)`
- Rounding increment: OHP = 2.5kg, Smith Squat = 5kg
